non-zero db_errors_total series and the API logs did not show database
exceptions. The only HTTP response metric for `/api/patients/recent` was

route. Because the middleware records metrics on `res.on('finish')`, this means
the failed k6 requests either were not accepted by the app or were aborted
before Express finished the response. The mechanism is connection-level
failure, such as accept-queue pressure or socket resets, not a database or
application 500 error. Combined with API CPU above MySQL CPU, this identifies
API/socket/request handling overload under 2000 VUs.
